# 刷题通功能筛查报告

检查日期：2026-10-10。范围是现有刷题、模拟考试、AI、编辑器、公共题库维护、设置与本机缓存；未创建新分支，未进行独立 UI 重设计。

## 检查结论

核心流程已验证，发现的问题已按下表修复。模拟考试切题重新打乱选项是用户用于“记内容、不记字母”的设计，明确保留；判分仍使用原始选项键，回顾展示使用当次显示字母。

| 功能 | 修复或结果 |
| --- | --- |
| 本地 JSON 导入 | 仅 JSON，带格式校验；本地数据不调用公共发布接口。空题干、非法选择键、空填空答案与重复题号会被拒绝。 |
| 文件名、题号预览、错题本、答案展示 | 原文件名、题干属性和填空答案可进入 HTML，已统一转义；可复现的脚本执行问题已阻断。 |
| AI 解析、纠错 | 切题取消旧请求并拒绝过期结果；避免上一题解析覆盖下一题。未配置时降级到本地参考，请求设有超时。 |
| AI 填空判分 | 旧题请求不再给新题记分；`"false"` 字符串等无效返回不再当真，退回本地比对；AI 反馈作为文字显示。 |
| 多选模拟考试 | 点选即记录，直接交卷不会漏选；取消全部选项后清除该题答案。 |
| 模拟考试回顾 | 重新洗牌保留；选中答案和正确答案文字与当次排列匹配。 |
| 历史错题重练 | 校验题库内容指纹，防止另一题库相同题号被当作原错题；旧记录仅保留成绩查看。 |
| 普通答题、重做、筛选、搜索 | 搜索同时作用于错题与考试错题筛选；已答题重做回退统计。自动下一题任务在人工切题后取消。 |
| AI 改编 | 修复完成按钮禁用/重复请求，生成结果做结构校验；改编题支持切题与显示答案。 |
| 题目编辑与插入 | 保存未修改选项不再丢公式/图片；取消编辑不再改原题；填空标准答案保留；重复选项和非法答案拒绝保存；插入位置 0 有效。 |
| 缓存恢复 | 旧数据缺省字段补齐，坏题库缓存不让页面崩溃；保存失败显示提醒。 |
| 开发者登录 | 一次登录复用服务授权，密码不存储，JWT 仅在标签页临时存储，退出清除；取消的旧登录不能清除新会话。 |
| 公共题库维护 | 新增、资料修改、JSON 替换、删除、文件重命名均有根权限和版本校验；目录/文件原子提交，同名目标与过期编辑拒绝。 |
| 已确认的小修 | 模板、同步、导出入口移除；简介全宽；背题有选中状态；手机顶部按钮缩到 34px、题库标题区收紧，保持两行对齐；底部两行拉开；模型从接口获取或手动填。 |

## 冗余与建议

### 已移除的入口

JSON 格式模板、旧同步、旧导出：按用户明确要求移除。公共维护入口统一使用题库池；题库下载仍在公共题库卡片中，和开发者导出按钮不是同一入口。

### 源码冗余候选（尚未删除）

| 候选 | 证据 | 建议 |
| --- | --- | --- |
| `src/parsers/` 与 `xlsx`、`mammoth` | 当前页面仅导入 JSON，主入口没有解析 Word/Excel 的调用。依赖仍保留用于旧模块类型检查。 | 可归档旧模块后移除依赖；不要直接卸载后留下编译错误。 |
| `src/ui/sync.ts` 与服务端个人同步、premium 注册/登录 | 当前 UI 没有同步入口，公共题库使用新的根权限发布接口。 | 若不再需要多设备私人同步，可整组移除；本轮未删后端能力。 |
| `exportQuestions()` | 已没有导出按钮调用；函数保留调试弹窗和临时下载链接。 | 可删除未使用函数及专用样式。 |
| 简单编辑器与完整编辑器 | 当前 root 开发者默认走完整编辑器；简单编辑器仍保留旧 tier 分支。 | 以后可合并；本轮修复两者的数据损失，不贸然替换行为。 |
| `legacy/shuatitong.html` | 单文件旧版不参与当前 Vite 构建。 | 保留为历史参考或移至独立归档。 |
| 同一题库在 `data/`、`public/` 与 `www/` 的副本 | 原始资料、公开资源与构建输出用途不同；部分旧 `public/merged_questions.json` 已不被目录引用。 | 可清理无引用旧资源；`www/` 是构建输出，不应逐个当垃圾删。 |
| AI 调试工具 | 与普通解析不是同一功能，主要用于接口排查。 | 非普通用户功能，继续仅在开发者模式显示，可后续收进高级工具。 |

### 不建议作为冗余删除

AI 解析与 AI 纠错分别用于详细讲解和快速定位选项错误；错题本与错题筛选分别提供列表和逐题练习；背题与显示答案分别是持续学习模式和单题操作；题库池与本地导入分别提供共享资源和个人资料。它们用途不同。

## 当前限制

- 模拟考试只存在内存中，刷新不能恢复作答。已加入离页提醒；若强制刷新仍丢进度。此轮没有扩展考试存储架构。
- 改编题暂存在内存，刷新不保留改编列表；恢复时回到普通题库。需要长期保存时，开发者应在维护流程发布确认过的 JSON。
- localStorage 容量有限，尤其 Base64 图片大题库会占空间；状态与最近打开有重复数据。已增加保存失败提醒，未迁移 IndexedDB。
- 当前题库切换会重置统计，并没有按每个题库独立保存答题进度。最近打开保存题库内容，不保存一套独立进度。
- AI 返回的知识内容和语义判分不等于人工核对。测试使用可控响应，只证明程序流程，不保证外部模型/网络可用。
- GitHub Pages 只读，公共维护要求开发者主机服务运行且有仓库写权限；Token 只在本机环境文件。仓库版本冲突需要重新读取后重试。
- APK 为测试包，未配置持久发布签名；卸载重装与浏览器清数据会丢失本地进度。实际 Android 设备安装和触控体验本轮未真机验证。
- 根依赖审计仍报告 12 个项目，其中包含旧 Word/Excel 解析和构建链传递依赖；本轮未执行有破坏风险的强制升级。开发者服务依赖审计为 0。
