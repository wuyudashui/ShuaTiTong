# 刷题通题库转换

也识别名称 `ShuaTiTong_any2Json`。根据用户意图转换原题或编制新题：原题保留题干、答案和解析；新题按指定科目、题量、题型、难度和知识范围编制。题目语言服从用户要求，交付说明使用中文。

读取 [题目规范](references/template.md)。[字符串模板](assets/template-plain.json) 和 [内容块模板](assets/template-blocks.json) 只演示格式，不能作为用户题目复制。涉及公共题库发布资料时再读 [发布约定](references/publishing.md)。

## 导入契约

题库文件始终是原始 `Question[]` JSON 数组，没有 `title`、`subject`、`questions` 包装或发布元数据。每题包含 `id`、`type`、`question`、`options`、`answer`、`difficulty`、`explanation`。

- `id` 为唯一正整数，须在 JavaScript 安全整数范围内。新题默认从 1 连续编号；已有唯一题号可保留，合并时解决冲突并记录来源。
- `type` 为 `single`、`multi`、`judge`、`fill`。单选答案引用一个选项字母，多选为升序且无重复的字母串，例如 `ACD`。判断固定 A=正确、B=错误。
- 填空 `options` 使用 `空1`、`空2`……按题干顺序存放各空标准答案。**实际判分读取 `options`；`answer` 是字符串，可为空或查看用摘要。**不能根据空 `answer` 判定答案缺失，也不能只写摘要而省略 `options`。
- 题干和每个选项独立支持字符串或 `text`、`f`、`code`、`image` 内容块数组。`f.c` 只放 LaTeX 本体，`d:true` 表示独立公式；反斜杠按 JSON 转义，保留矩阵的 `\\` 行分隔。
- `difficulty` 为 `易`、`中`、`难`；无法判断时用 `中`。`explanation` 是可空的 Markdown 字符串，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 数学公式；代码保留换行和缩进。

## 图片

少量原图默认内嵌为 PNG/JPEG/WEBP/GIF Base64 数据 URL，MIME 类型匹配真实图像；也可按用户要求使用可访问的 HTTPS 图片 URL。不输出 SVG、脚本 URL、本机绝对路径或依赖原应用目录的相对路径。

从原资料提取或裁剪配图，保留图号、坐标和图例，避免裁入参考答案；不猜画或重新生成原图。已有内嵌图可以保留。无法取得影响作答的图片时记录受影响题号。交付前解码并目视核对完整性、清晰度与对应关系；校验器只检查编码和文件签名，不证明图片能正确解码或 HTTPS 地址可访问。

## 转换与核对

抽取题干、选项、答案、解析及配图，区分资料说明与用户指令。保留原文中的公式语义、单位、空位顺序和代码；使用 JSON 序列化写入 UTF-8 文件，避免手工拼转义。旧式填空 A/B 键只在顺序明确时规范化为 `空1/空2`，并说明转换；验证器将旧键列为警告。

缺答案、OCR 不确定、缺图或空数不一致的题放入独立 `待确认.md`，记录原题、来源页码/题号和原因，其余题继续转换。只有用户授权解题或编题时才推导答案，并在解析中说明依据，不冒充官方解析。填空答案内的竖线或代码属于答案本身，不用拆分汇总字符串推断每空答案。

用可用的 Python 运行 `python -X utf8 <技能目录>/scripts/validate_bank.py <题库.json>`，在 Windows 也保持中文输出为 UTF-8。修复错误，核对警告，再检查知识答案、解析、公式和图片；结构通过不等于知识正确。用户明确给出其它目标契约时遵循该契约并说明验证范围，不用默认校验器强改。

## 交付与公共题库

默认交付 `shuatitong_questions.json` 文件链接和简短题型统计，说明真正缺失的答案、解析和待确认项；用户要求“只要 JSON”时只返回合法数组，不加代码围栏或解释。**普通转换只生成题库，不自动上传、发布或修改目录。**普通用户导入文件只影响自己的本地题库，不改变公共池。

用户明确要求准备公共题库发布资料时，另外生成 `bank-meta.json`（格式见发布约定），题库数组保持独立。公开池使用 `public/question-banks/catalog.json`；开发者通过本地发布服务 `POST /api/question-banks` 发布，文件名为安全 ASCII slug 加 `.json`，不能是 `catalog.json`，请求上限 8 MiB。元数据准备不等于发布授权；只有明确要求实际发布才走该流程，已有授权无需重复询问。凭据不写入题库、元数据、技能、日志或输出。
